# 아키텍처 결정 기록

## 첫 출시 탐색 지역 개편

- 결정일은 2026-11-26이다.
- 익선동 중심의 탐색 범위를 종로~을지로로 넓히고, 해방촌을 용산에 통합한다.
- 첫 출시 지역은 용산, 성수~서울숲, 연남, 종로~을지로, 서촌, 북촌으로 6곳이다. 용산 slug는 `yongsan`을 유지하고 종로~을지로는 `jongno-euljiro`를 사용한다.

### TourAPI 지역 자동 배정

TourAPI의 법정동 시군구 코드와 서울 주소의 자치구 이름이 일치하고, 주소에 아래 법정동이 명시되어 탐색 지역 하나로만 연결될 때 자동 배정한다.

| 탐색 지역 | 자치구와 법정동 |
| --- | --- |
| 용산 | 용산구 한강로1가·2가·3가, 이촌동, 용산동2가. 해방촌 후보도 용산에 포함한다. |
| 성수~서울숲 | 성동구 성수동1가·2가 |
| 연남 | 마포구 연남동 |
| 종로~을지로 | 종로구 익선동·낙원동·돈의동·관수동·관철동·종로1~4가, 중구 을지로1~4가·수표동·입정동·산림동·주교동 |
| 서촌 | 종로구 통인동·누상동·누하동·옥인동·체부동·필운동 |
| 북촌 | 종로구 가회동·계동·원서동·삼청동·재동 |

필수 주소를 해석할 수 없거나, 도로명만 확인되거나, 자치구가 충돌하거나, 여러 탐색 지역에 해당하는 후보는 검토 대상으로 남긴다. 좌표는 공개 필수값으로 검사한다. 주소만으로 판단이 어려운 후보에 좌표를 사용하려면 검증된 지역 경계가 필요하다. 자동 공개는 지역 배정 외에 이름·주소·좌표·카테고리 유효성과 중복 검사도 통과해야 한다.
